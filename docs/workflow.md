# Workflow — Task 2: список нотаток

Фіча: веб-сторінка зі списком нотаток на `/` (Next.js App Router, client-side + localStorage).

## Acceptance criteria

### AC1. Сторінка відображає список нотаток
**Given** користувач відкриває `http://localhost:3000` після `npm run dev`  
**When** у localStorage уже є збережені нотатки  
**Then** на сторінці видно заголовок «Нотатки» і список усіх нотаток — кожна з текстом і діями «Редагувати» / «Видалити».

### AC2. Користувач може додати нову нотатку
**Given** відкрита головна сторінка  
**When** користувач вводить непустий текст у поле і натискає «Додати» (або Enter)  
**Then** нова нотатка одразу з'являється в списку без перезавантаження сторінки.

### AC3. Порожні нотатки не додаються і не зберігаються при редагуванні
**Given** поле вводу порожнє або містить лише пробіли  
**When** користувач натискає «Додати» **або** «Зберегти» під час редагування  
**Then** нотатка **не** додається / зміни **не** зберігаються; попередній текст нотатки лишається без змін.

### AC4. Користувач може видалити нотатку
**Given** у списку є хоча б одна нотатка  
**When** користувач натискає «Видалити» біля конкретної нотатки  
**Then** ця нотатка зникає з UI; інші нотатки лишаються на місці.

### AC5. Користувач може редагувати існуючу нотатку
**Given** у списку є нотатка з текстом «Старий текст»  
**When** користувач натискає «Редагувати», змінює текст на «Новий текст» і підтверджує «Зберегти»  
**Then** у списку відображається оновлений текст; інші нотатки не змінюються.

### AC6. Нотатки зберігаються між сесіями (localStorage)
**Given** користувач додав, відредагував або видалив нотатки  
**When** сторінку перезавантажено (F5)  
**Then** список відображає той самий набір нотаток (включно з відредагованим текстом), що був до refresh.

## Plan mode

1. Сформульовано початкові AC (5 пунктів): перегляд, додавання, валідація порожнього тексту, видалення, localStorage.
2. Уточнено scope через діалог: localStorage + add/delete.
3. Після рев'ю плану **додано редагування** (AC5) і розширено AC3 на save при edit; AC6 — persistence після edit.
4. Узгоджено UX: inline-редагування в `NoteItem` з «Зберегти» / «Скасувати».

## Agent mode

1. Реалізовано `useNotes` hook (`addNote`, `updateNote`, `deleteNote`) з ключем `notes-app-v1`.
2. Компоненти: `NoteForm`, `NoteList`, `NoteItem`, `NotesApp`.
3. Головна сторінка `app/app/page.tsx` замінена на notes UI.
4. Запущено `npm run build` і `npm run lint`.

## Ручна перевірка

| AC | Результат |
|---|---|
| AC1 | Заголовок і список з кнопками «Редагувати» / «Видалити» |
| AC2 | Додавання через форму та Enter |
| AC3 | Порожній текст не додається; при save edit — відкат до попереднього тексту |
| AC4 | Видаляється лише обрана нотатка |
| AC5 | Inline edit оновлює текст у списку |
| AC6 | Після F5 дані з localStorage відновлюються |

## Що скоригували після Plan-рев'ю

- Додано **редагування** (спочатку було поза scope).
- AC3 поєднано для add і edit save.
- Persistence (AC6) явно включає відредаговані нотатки.
