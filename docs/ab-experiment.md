# A/B Experiment — Task 4 (bonus)

## Prompt A — базовий

Зроби на головній сторінці список нотаток з формою для додавання нових.


**Результат:** ~2 ітерації, ~120k input tokens (~$0,45). Отримано MVP: форма + список + валідація порожнього тексту. Без localStorage, редагування та видалення — scope не зафіксований.

## Prompt B — структурований

Роль: Next.js/React розробник. Читай app/AGENTS.md.

Контекст: App Router (app/app/), Tailwind 4, TypeScript strict, @/*.
Client-side only, без backend.

Задача: список нотаток на / з localStorage (ключ notes-app-v1).

Acceptance criteria:
1. Заголовок «Нотатки»; кожна нотатка — «Редагувати» / «Видалити».
2. Форма додає непусту нотатку (Enter або «Додати») без reload.
3. Порожній текст не додається і не зберігається при edit.
4. Видаляється лише обрана нотатка.
5. Inline edit: textarea + «Зберегти» / «Скасувати».
6. Після F5 дані з localStorage відновлюються.

Обмеження: компоненти в app/components/, hook useNotes; npm run build && lint — OK.

Формат: короткий план файлів → реалізація.

**Результат:** ~11 ітерацій (Plan + Agent + 2 bugfix), ~890k input tokens (~$2,97). Усі 6 AC виконані з першого узгодженого плану; вища якість і передбачуваний scope.

## Висновок

Базовий промпт швидший і дешевший, але дає неповну фічу — доведеться допитувати агента окремо. Структурований промпт (роль + контекст + AC + обмеження) дорожчий на старті, зате одразу закриває Definition of Done і зменшує scope creep. Для homework і PR доцільніший структурований підхід; базовий — лише для швидкого прототипу.
